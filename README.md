# VELES

**VELES** — локальный инструмент оценки риска файлов для Windows.

VELES предназначен для выявления потенциально опасных свойств файлов *до их запуска*, что помогает снизить риск компрометации пользовательской системы.

---

## Цель проекта

Создать простой и понятный инструмент класса *file risk scanner*,  
который позволяет пользователю или специалисту по информационной безопасности быстро оценить степень опасности файлов на основе набора эвристических признаков.

Проект является учебно-практическим (pet-project) и ориентирован на демонстрацию понимания принципов Windows Security, анализа файлов и безопасного кодирования.

---

## Основные возможности

- Рекурсивное сканирование файлов и каталогов  
- Удобный выбор директорий для анализа:
  - Рабочий стол  
  - Загрузки  
  - Документы  
  - AppData\Local\Temp  
  - Program Files / Program Files (x86)  
  - ввод пользовательского пути  
- Определение **Mark-of-the-Web (Zone.Identifier)**
- Обнаружение файлов с двойным расширением  
  (например: `invoice.pdf.exe`)
- Анализ потенциально опасных типов файлов:
  - исполняемые файлы (`.exe`, `.dll`, `.scr`)
  - скрипты (`.ps1`, `.vbs`, `.js`, `.bat`, `.cmd`, `.hta`)
- Учет расположения файла в подозрительных каталогах  
  (`AppData`, `Temp`, `ProgramData`)
- Дополнительный риск для архивов (`.zip`, `.rar`, `.7z` и др.)
- Эвристическая оценка риска (risk score)
- Формирование детального отчёта в формате **JSON**
- Понятный вывод причин, повлиявших на оценку файла

---

## Используемые эвристики

Текущая версия VELES учитывает следующие факторы риска:

- наличие Mark-of-the-Web (файл загружен из Интернета)
- двойное расширение файла
- потенциально опасный тип файла
- нахождение в подозрительных каталогах
- принадлежность к архивным форматам

Каждому фактору назначаются баллы, формирующие итоговый **risk score**.

---

## Как работает программа

После запуска пользователь выбирает директорию для анализа.  
Далее VELES:

1. Рекурсивно обходит все файлы в указанной папке  
2. Анализирует каждый файл по набору правил  
3. Вычисляет риск-оценку  
4. Выводит список подозрительных объектов  
5. Формирует подробный JSON-отчёт

VELES не является антивирусом и не заменяет средства защиты конечной точки.  
Инструмент предназначен для анализа файлов и повышения осведомлённости пользователя о потенциальных угрозах.
