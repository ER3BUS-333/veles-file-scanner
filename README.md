# VELES
**VELES** - инструмент анализа риска файлов для Windows.
VELES предназначен для выявления скрытых и потенциально опасных свойств файлов *до их запуска*, что снижает риск коспрометации пользовательской системы.


## Цель проекта
Создать локальный инструмент класса *file risk scanner*, 
который помогает пользователю или специалисту по Информационной безопасности оценить 
степень опасности файлов на основе эврестических признаков.

Проект является учебно-практическим (pet-project) и ориентирован 
на демонстрацию понимания принципов Windows Security и Secure Coding.


##  Основные возможности
- Рекурсивное сканирование файлов и каталогов
- Определение **Mark-of-the-Web (Zone.Identifier)**
- Обнаружение файлов с двойным расширением
- Анализ потенциально опасных типов файлов:
  - скрипты (`.ps1`, `.vbs`, `.js`, `.bat`)
  - офисные документы с макросами (`.docm`, `.xlsm`)
- Эвристическая оценка риска (risk score)
- Формирование отчёта в формате JSON / HTML


##  Используемые эвристики
- наличие Mark-of-the-Web
- двойное расширение (например `invoice.pdf.exe`)
- тип файла
- расположение в подозрительных каталогах
  (`Downloads`, `AppData`, `Temp`)
- недавнее время создания файла


##  Платформа
- Windows 10 / 11
- Python 3.11+


##  Статус проекта
Проект находится в активной разработке.
Функциональность будет расширяться поэтапно.

##  Дисклеймер
VELES не является антивирусом и не заменяет средства защиты конечной точки.
Инструмент предназначен для анализа и повышения осведомлённости пользователя.
